# 小马课表

零广告的大学生课程表 App（Flutter / Android）。

## 功能

- **周视图课表**：按周浏览课程，本周课程优先渲染、非本周课程淡化；同格多课有「+N」角标与选择列表；午休 / 晚间分隔带；周末无课时自动收起为 5 列；切周、选周、长按均有触感反馈。
- **课程管理**：手动新建 / 编辑课程，莫兰迪色系配色，支持「新增本课其他时段」快捷录入；周次支持单双周与区间表达式。
- **课表导入**：支持 ICS 文件、课表截图 OCR、PDF 导入，导入后进入人工核对页逐项确认，并做冲突检测（覆盖冲突延迟删除，避免误删旧课）。
- **作息时间设置**：每节课起止时间可自定义，导入与显示均以作息表为准。
- **多学期管理**：新建、切换、删除学期，课表、提醒、小组件随当前学期联动。
- **课前提醒**：本地通知 + 精确闹钟（每日重排），提醒提前量可设置（默认 15 分钟），开机后自动恢复。
- **桌面小组件**：4×2 今日课程小组件；今日课程全部结束或 20:00 后自动显示明日课程预告。
- **今日课程常驻通知栏**：常驻通知实时展示今日剩余 / 明日课程。
- **深色模式**：跟随系统 / 手动三档主题，莫兰迪配色有深色降饱和适配。
- **备份与导出**：全量数据 JSON 备份与恢复；当前学期可导出 ICS 文件。
- **考试倒计时**：为课程设置考试日期后按时间排序倒计时展示。
- **单次调课 / 停课**：基于课程覆写（override）实现某一次课的临时调整，不影响整门课程安排。

## 构建方法

环境要求：Flutter 3.47.x（stable），Android SDK（打 APK 时需要）。

```bash
flutter pub get        # 拉取依赖
flutter run            # 真机 / 模拟器调试运行
flutter build apk      # 构建 Android 安装包
flutter analyze        # 静态检查（应为零问题）
flutter test           # 单元测试（应全部通过）
```

## 技术栈

- Flutter 3.47.7 / Dart 3（空安全）
- sqflite + path（本地数据库）
- flutter_riverpod（状态管理，手写 Notifier）
- flutter_local_notifications（本地通知）、home_widget（桌面小组件）
